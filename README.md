Assignment #1. HTML & CSS Basics

Objective:
By the end of this assignment, students will be able to:
    • Understand the role of CSS in web development.
    • Apply CSS properties to style colors, fonts, and page backgrounds.
    • Create structured webpage layouts using CSS (colors, fonts, margins, padding, borders).
    • Design visually appealing webpages by combining HTML structure with CSS styling.
Rules for Submission:
    1. The assignment must be completed individually. If you have the same paperwork with other students, you will have 0 to this work.
    2. The assignment must be submitted by the deadline which is specified in the moodle.astanait.edu.kz. Works submitted after the deadline will not be accepted! To receive a grade, you must submit by deadline and defend your work at practice lesson time. If you do not defend your assignment, your grade will be 0
    3. Your project must be published using GitHub Pages or Netlify.
    4. Submit the GitHub repository link containing your completed assignment. Include a README.md file with a brief description and instructions.Create a navigation bar (navbar) that links to the different tasks/parts of the assignment across separate pages.
Task 1. Introduction to HTML & CSS
Requirements:
    1. Create a personal webpage using HTML and CSS.
    2. Create index.html and styles.css and link the CSS file to HTML.
    3. Add:
        a. Heading (h1, h2)
        b. 2–3 paragraphs
        c. Ordered list (ol) with at least 4 items
        d. Unordered list (ul) with at least 4 items
        e. Image (img) with alt attribute
        f. At least 2 links (a)
    4. Apply CSS styling:
        a. Set a background color.
        b. Change font family, size, and colors.
        c. Add margin, padding, and borders.
        d. Style the image with border-radius and max-width.
        e. Add a hover effect to links.
    5. Use at least 3 CSS selectors:
        a. Element selector
        b. Class selector
        c. ID selector
    6. Create a simple profile card containing your image, name, group, and a short description.
    7. Make the webpage visually organized and responsive.

Task 2. Simple webpage layout (using <div> + positioning / floats — no Flexbox or Grid)
Requirements:
Create a webpage layout using only <div> elements and CSS positioning (no flexbox or grid).
The webpage must include the following sections:
        1. Header - with the title of the website.
        2. Navigation bar – at least 4 navigation links, linked with tasks 
        3. Sidebar menu – on the left, containing a list of at least 3 items.
        4. Main content (Aside section) – on the right, with a heading and a short paragraph.
        5. Footer – at the bottom with copyright text.
CSS Styling:
    1. Apply background colors and padding for each section.
    2. Float the sidebar menu to the left and the aside content to the right.
    3. Style the navigation links (hover effects, spacing, colors).
    4. Add borders, margins, or box-shadows to make sections visually distinct.
Output expectation:
A simple page with a header at the top, a navigation bar below it (with the links to the tasks, a two-column layout in the middle (menu on the left, content on the right), and a footer at the bottom.

Task 3. Tribute page (Create a tribute page for a famous person of your choice.)
Step 0. Create the files and boilerplate
    1. Create a folder named exercise1.
    2. Inside it create index.html and styles.css.
    3. Add the basic HTML boilerplate to index.html and link the CSS 
Step 1. Structure text using HTML tags
    1. Add a main heading <h1> with the page title.
    2. Add a subheading <h2> for “About *”.
    3. Add a short paragraph <p> (3–5 sentences) that summarizes  life (birth/death years + one sentence about inventions).
    4. Add a smaller heading <h3> if you want to show birth/death or a short tagline (optional).
Step 2. HTML Lists
    1. Create an ordered list <ol> that shows 4–6 important events
    2. Create an unordered list <ul> listing key inventions/contributions
Step 3. Images and Links
    1. Insert a portrait using <img> with a descriptive alt attribute.
    2. Add at least two clickable links <a>
    3. Add a “Learn more” button that links to Wikipedia (styled later with CSS).
Step 4. Apply CSS styling
    1. Set page background (solid color or subtle gradient).
    2. Use at least two fonts (link Google Fonts in the HTML <head> and apply in CSS).
    3. Style the header: background color, text color, padding, center alignment.
    4. Style the .content container: max-width, margin: 0 auto, padding.
    5. Style the image: max-width, border-radius, box-shadow, optional border.
    6. Style headings and paragraphs (font sizes, line-height, colors).
    7. Style lists (change list-style-type, spacing).
    8. Style links and the .btn (hover effect, padding).

Task 4.CSS Table and FORM
Exercise: Table Styling
Requirements:
    1. Create a webpage with a table that displays student grades.
    2. The table must include at least 3 columns (e.g., Name, Subject, Grade) and 3–4 rows of data.
    3. Apply the following CSS styling:
    4. Set a background color for the table header.
    5. Add borders for all cells.
    6. Use padding for table cells to make text readable.
    7. Apply alternate row colors using nth-child.
    8. Highlight one row with a different background color using a class (e.g., .highlight-row).
    9. Center-align text inside cells.
    10. Use Rowspan or Colspan attribute to merge cells
    11. Add a page heading above the table with an ID selector for custom styling.
Exercise: Form Styling
Requirements:
    • Create a feedback form with the following fields:
        1. Text input for name.
        2. Email input for email address.
        3. Select dropdown for role (e.g., Student, Teacher, Other).
        4. Radio buttons for Yes/No type question.
        5. Textarea for comments.
        6. A submit button.
    • Apply the following CSS styling:
        1. Center the form on the page with a fixed width.
        2. Add background color, padding, and rounded corners for the form container.
        3. Style labels with bold text.
        4. Style input fields, textarea, and dropdown with consistent width and spacing.
        5. Style the submit button with background color, hover effect, and rounded corners.
        6. Use at least one ID and one class in your CSS.

Task 5. Midterm Project: Topic & Wireframe Design
Choose a topic for your midterm project (e.g., Portfolio Website, Online Store, Restaurant Website, Blog, Task Manager). Create a wireframe/design frame for your project using tools such as Figma, Wireframe.cc, or Balsamiq. This is a group project. Each group can have up to 3 students.
Requirements:
    1. Your website should include at least 5 pages. Each page must have a consistent header, footer, and navigation
    2. Create a sitemap (navigation structure) showing how the pages are linked.
    3. Design wireframes for each page layout only (no need for colors or real images).
    4. Each page must include:
        ◦ Header (logo + navigation menu)
        ◦ Main content area (depends on the page topic)
        ◦ Footer (contact info, copyright, or links)
    5. Submit your wireframes as images or as a link (if using Figma/online tool).
    6. Write a short project description (3–5 sentences): explain your topic, target users, and purpose of the website.
